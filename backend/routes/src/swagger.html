🌾 MkulimaLink API

Farmer-to-buyer marketplace for Tanzania — Connecting farmers with buyers via mobile, USSD, and SMS

🔐 Testing Authenticated Endpoints

  1. Use POST /api/v1/auth/login with admin credentials to get an access token
  2. Click the green Authorize button (top right)
  3. Enter: Bearer <your-access-token>
  4. All authenticated endpoints are now unlocked for testing!
